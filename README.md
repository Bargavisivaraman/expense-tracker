# 💸 SpendSmart — Expense Tracker

A dark techy expense tracker with charts, budget alerts & localStorage persistence.

## features

- 💰 **Monthly Budget** — set a budget with live progress bar & alerts
- ⚠️ **Smart Alerts** — warning at 80%, danger at 100% budget used
- ➕ **Add Expenses** — name, amount, category, date
- 🍩 **Donut Chart** — spending breakdown by category (Chart.js)
- 📈 **Line Chart** — daily spending over last 14 days
- 📊 **Summary Stats** — total, count, average, top category
- 🔍 **Filter & Sort** — by category, newest/oldest/highest/lowest
- 💾 **localStorage** — all data persists across sessions
- 🌑 **Dark Techy Theme** — green-on-dark with grid background

## project structure

```
expense-tracker/
├── index.html   ← structure
├── style.css    ← dark techy styling
├── script.js    ← all logic + Chart.js integration
└── README.md    ← this file
```

## tech stack

- HTML5 + CSS3 (CSS variables, animations, grid/flexbox)
- Vanilla JavaScript
- Chart.js (donut + line charts)
- localStorage API

## how to run

```bash
git clone https://github.com/Bargavisivaraman/expense-tracker
cd expense-tracker
open index.html
```
